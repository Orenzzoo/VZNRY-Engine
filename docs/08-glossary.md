# Glossary

| Term | Meaning |
| --- | --- |
| **DTC** | Direct-to-consumer brand that sells online. Our main client type. |
| **Batch** | One generation run for a product or brief: a set of pieces made together. |
| **Piece / clip** | One finished video (in one or more sizes). |
| **Brand kit** | Everything ads must get right about a product: images, facts, voice, visuals, guardrails. |
| **Hero image** | The main product photo the video models copy. |
| **Product cutout** | Product photo with the background removed, used as a reference in shots. |
| **Guardrails** | Words and claims that are automatically blocked. |
| **Voice of customer (VoC)** | Real phrases buyers use, gathered from comments and reviews. Become hooks. |
| **Pain / desire / objection / aha** | Types of VoC phrase: what annoys them, what they want, why they hesitate, what wins them over. |
| **Awareness stage** | How ready a buyer is (unaware → problem aware → solution aware → product aware → most aware). Decides what the hook leads with. |
| **Persona** | A type of buyer found in research, with its own best angle. |
| **Hook** | The first 1–3 seconds of an ad, meant to stop the scroll. |
| **Core** | The middle of an ad (problem, demo, story). |
| **CTA** | Call to action, the ending that tells people what to do. |
| **Master Cut** | The smallest set of stitched ads that shows every approved hook, core and CTA at least once. |
| **Recipe** | A tested video format: structure, shot types, prompt templates, model routing. |
| **Pass %** / **QA pass** | Share of a recipe's shots that pass the automatic quality check. |
| **Director layer** | The step that turns a script into a shot list and model-specific prompts. |
| **Shot list** | A video broken into short clips, each generated separately. |
| **Model** | The AI tool that makes a given shot (avatar lip-sync, image-to-video, etc.). |
| **Quality score** | Automatic 0–100 check per shot. **Fixed** = failed once and was remade. |
| **Blank** | A `{word}` in a prompt template that the engine fills per product. |
| **Locked line** | A prompt line starting with `!`; never changed by tweaks. |
| **Tweak** | A per-product change the engine made to a custom prompt, shown with a reason. |
| **Brief** | A plain-language description used to start ads that have no product page. |
| **Series** | A saved brief that keeps the character, look, promo and structure for one-click episodes. |
| **Locked promo** | The promo segment in a brief, made once and reused unchanged in every episode. |
| **Style frame** | A single still showing an animation's look before any video is made. |
| **Character sheet** | A character drawn in several poses, used so it never changes shape between shots. |
| **Consistency / match %** | How often test shots look like a character's reference photos. |
| **Review round** | One cycle of sending pieces to a client for approval. Fixes go out as the next round. |
| **Hold rate** | Share of viewers still watching after 3 seconds. |
| **ROAS** | Return on ad spend: revenue for every $1 spent on ads. |
| **CTR** | Click-through rate. |
